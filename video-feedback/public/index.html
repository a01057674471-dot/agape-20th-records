▶ 영상 피드백
영상을 여기에 끌어다 놓으세요 파일 이름으로 프로젝트가 만들어집니다 · 또는 Claude가 렌더하면 자동으로 올라옵니다
Claude와 함께 쓰는 법
  1. Claude가 영상을 렌더하면 node video-feedback/cli.mjs upload <프로젝트> out.mp4 로 올립니다 (또는 video-feedback/inbox/ 폴더에 넣기).
  2. 고칠 장면에서 멈추고 화면을 클릭해 주석을 남깁니다.
  3. Claude에게 “피드백 반영해줘”라고 하면 주석(시간·위치·스냅샷)을 읽고 수정한 새 버전을 올립니다.
  4. 체크리스트 탭에서 모든 수정이 반영됐는지 확인하고 완료 처리합니다.
