### 2. 브랜드 20초 쇼릴

쓰는 곳: 브랜드 소개 영상, 프로필 고정 릴스, 행사 오프닝. 원작자: @prasenx, @HO_BA

```
네가 세계 최고 수준의 모션 디자이너라고 보여 주는 20초짜리 모션그래픽 쇼릴을 만들어 줘. 이력서에 붙이는 쇼릴처럼, 아끼지 말고 전부 쏟아부어.
주인공은 [브랜드 이름]이야.

형식
- HTML 파일 하나(외부 이미지·영상 파일 없이 코드로만 그림). 1920x1080, 30fps, 정확히 20초, 소리 없음.
- 템포 120BPM 기준: 모든 컷과 전환이 0.5초 박자에 맞아떨어지게.
- 색은 [색 다섯 가지, 예: 거의 검정·빨강주황·전기 파랑·라임·흰색]만.
- 화면 글자는 전부 한국어, 아주 크고 굵게(폰 화면에서도 바로 읽히게, 핵심 단어는 화면 높이의 25% 이상).
- 다른 회사 로고·실존 브랜드는 쓰지 마.

장면(서로 완전히 다른 세계를 빠르게 넘나들 것, 장면마다 1.5~2.5초)
1. 어두운 격자 위에 곡선이 그려지고, 빛나는 점이 곡선을 따라 가속하다 화면 밖으로 튕겨 나간다.
2. 색 화면이 덮치며 '[브랜드 이름]'이 한 글자씩 꽂힌다.
3. 원·사분원·삼각형 타일 격자가 가운데부터 물결처럼 뒤집힌다.
4. 수천 개의 입자가 한곳으로 빨려 들어가 '[핵심 단어 1]' 글자를 만든다.
5. 네온 터널을 카메라가 빠르게 뚫고 들어간다.
6. 액체 마블 무늬 위에 외곽선만 있는 거대한 '[핵심 단어 2]' 글자.
7. 입체 큐브 수백 개가 파도처럼 오르내린다.
8. 박자마다 배경색이 바뀌는 한 단어 컷 세 개: '[단어]' → '[단어]' → '[단어]'.
9. 마지막 3초: 가운데 [브랜드 이름] 로고 글자가 조립되고, 아래 '[한 줄 소개] · [계정]'.

규칙
- 모든 움직임은 시간 값 하나로만 계산(같은 프레임은 항상 같은 그림). 무작위는 시드 고정.
- 장면 사이 전환은 잘라 붙이지 말고 앞 장면의 물체가 다음 장면이 되게.
- 빠른 움직임엔 모션블러, 도착은 길게 감속, 퇴장은 짧게. 밋밋한 페이드 금지.
- 다 만들면 0.5초 간격으로 프레임을 직접 확인하고, 글자 잘림·빈 화면·겹침이 있으면 고쳐서 다시 확인해.
```

### 15. 보자마자 와 소리 나는 우주 영상

```
보자마자 "와" 소리가 나오는 우주 영상을 만들어 줘. 주제는 '[주제, 예: 성운 속에 숨은 블랙홀]'이야.

장면 순서
1. 처음 2초: 붉은 갈색과 청록색 가스 구름(성운)이 화면을 가득 채우고, 뒤로 별이 반짝여.

4. 원반에서 다가오는 쪽은 더 밝고, 멀어지는 쪽은 더 어둡게.
5. 마지막 5초: 카메라가 원반 바로 옆을 스치듯 돌아 지나가.

색과 빛
- 원반 안쪽은 흰색에서 금색, 바깥은 주황.
- 주변 구름은 원반 빛을 받아 따뜻하게 물들고, 멀수록 어두운 청록.

- 모든 화면을 시간 t로만 계산하는 window.seek(t) 함수를 만들어 줘(랜덤도 고정값으로). 그래야 한 프레임씩 녹화해도 끊기지 않아.
```
