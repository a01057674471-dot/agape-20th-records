# 코드로 그리는 모션 영상

영상 생성 AI를 쓰지 않는다. 화면에 그림을 그리는 코드를 HTML 한 파일로 짜고, 그 화면이 움직이는 것을 녹화해서 영상으로 만든다.

프롬프트 전문은 [prompts.md](prompts.md)에 있다. 번호로 찾아 쓴다.

## 진행 순서

1. 요청에 맞는 틀을 아래 표에서 고른다. 딱 맞는 게 없으면 가장 가까운 틀을 고쳐 쓴다.
2. `prompts.md`에서 그 번호의 프롬프트를 읽고 `[ ]` 칸을 사용자 내용으로 채운다. 대화에 이미 나온 정보(이름, 색, 문구)는 다시 묻지 말고 채운다. 꼭 필요한 칸이 비면 그것만 묻는다.
3. 채운 프롬프트를 지시로 삼아 HTML 한 파일을 직접 만든다.
4. 만든 뒤 여러 시점의 프레임을 직접 확인해 글자 잘림, 빈 화면, 겹침을 고친다.
5. 저장 방법(아래 "녹화")을 한 줄로 알려 준다.

## 모든 영상에 공통으로 지킬 것

- HTML 파일 하나. 외부 이미지·영상·글꼴 파일 없이 코드로만 그린다. 열면 바로 자동 재생된다.
- 글자는 한국어로 크고 굵게, 한 화면에 한 문장만. 휴대폰에서도 바로 읽혀야 한다.
- 처음 1초 안에 움직임이 시작된다.
- 색은 사용자가 준 브랜드 색만 쓴다.
- 숫자, 연도, 후기, 사실은 사용자가 준 것만 쓴다. 지어내지 않는다.
- 다른 회사 로고나 실존 브랜드를 넣지 않는다.
- 모든 움직임은 시간 값 하나로 계산한다(같은 시각은 항상 같은 그림). 무작위 값은 시드를 고정한다. 프레임 단위 녹화가 필요하면 `window.seek(t)`를 둔다.
- 장면 전환은 앞 장면의 물체가 다음 장면이 되게 잇는다. 도착은 길게 감속, 퇴장은 짧게. 밋밋한 페이드는 피한다.

## 녹화

- 맥: Shift + Cmd + 5 → '선택 부분 기록' → 미리보기 창만 잡고 녹화.
- 윈도우: 캡처 도구(Snipping Tool)의 녹화 기능.
- 미리보기 창을 전체 화면으로 띄우고 녹화하면 화질이 좋다.
- 14번은 마우스로 돌리고 '분해' 버튼을 누르는 모습까지 찍는다.

## 권리

프롬프트와 원본 영상의 권리는 각 원작자에게 있다. 결과물을 광고·판매 등 상업적으로 쓰기 전에는 원작자에게 먼저 확인하라고 사용자에게 알린다. 원작자 계정은 `prompts.md`의 각 항목에 적혀 있다.
