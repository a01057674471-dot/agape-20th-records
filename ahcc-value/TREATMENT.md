# 라파힐 AHCC — 30초 세로 광고, 가치 중심 편집 (Swiss Motion Graphics)

- 규격: 1080×1920(9:16), 24 fps, 30초. 음악 + 효과음, 나레이션은 후작업(`voices/narration.wav`를 넣고 `sh build.sh`).
- 이전 편집(`../ahcc-ad/`)에 "임팩트가 없고 고객이 가져갈 가치가 안 보인다"는 피드백이 있었다. 정보를 늘어놓는 대신 **고객에게 고르는 기준 3가지를 주고, 제품이 그 기준을 하나씩 통과**하는 구조로 바꿨다. 고객이 가져가는 가치는 "어떤 면역 제품이든 쓸 수 있는 판단 기준"과 "그 기준을 다 통과한 선택지"다.
- 임팩트: 남색 전면 카드와 종이 카드를 번갈아, 아주 큰 숫자와 글씨, 아래에서 올라오는 색 전환, 기준마다 크게 찍히는 ✓ 도장(이 영상의 유일한 튀는 움직임), 첫 프레임부터 킥 드럼, 도장마다 킥 + 크래시.

| 시간 | 카드 | 화면 |
|---|---|---|
| 0–3.5 | 01 질문 (남색) | 면역 제품, 뭘 보고 고르세요? / 똑같아 보이는 "면역" 상자 12개 |
| 3.5–6.5 | 02 기준 (종이) | 거대한 3 / 가지만 확인하세요 |
| 6.5–11.25 | 03 기준 01 (남색) | 식약처가 인정한 기능성인가? → ✓ 식약처 개별인정 제2008-78호 · 면역기능 증진에 도움을 줄 수 있음 |
| 11.25–16 | 04 기준 02 (종이) | 사람에게서 확인됐는가? → ✓ 인체시험으로 확인 · 수지상세포 증가 · NK세포 활성 / 논문 출처 |
| 16–20.75 | 05 기준 03 (남색) | 오래 검증된 원료인가? / 30년+(카운트) → ✓ 오래된 데는 이유가 있다 · 1980년대 개발 · 30년 넘는 연구 |
| 20.75–25.75 | 06 결론 (종이) | ✓ 식약처 인정 기능성 ✓ 인체시험 근거 ✓ 30년 넘게 연구된 원료 / 건강기능식품 · 식품이력추적관리 · GMP / 3가지 모두, 라파힐 AHCC + 제품 사진 |
| 25.75–30 | 07 가치 + 행동 (남색) | 면역의 기본, 근거로 고르세요 / 라파힐 AHCC / 프로필 링크에서 만나보세요 → |
| 11.25–30 | 하단 | ※ 시험결과가 모든 사람에게 동일하게 나타나는 것은 아닙니다. |

모든 문구는 초당 6자 + 1.5초 기준을 통과한다(`readcheck --cjk-cps 6`).
