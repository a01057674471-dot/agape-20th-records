# 올리고파 — 42초 세로 광고, 가치 중심 편집 (Swiss Motion Graphics)

- 규격: 1080×1920, 24 fps, 42초. 음성·배경음악 없음, 인쇄물 효과음만.
- 이전 편집(`../oligopa-swiss/`)에 "그래서 보는 사람에게 뭐가 좋은지 안 나온다"는 피드백이 있었다. 성분 나열을 앞에 두지 않고, **보는 사람의 상황 → 해결 → 이유 → 루틴 → 제품 → 행동 유도** 순서로 다시 짰다.
- 제품 분류: 건강기능식품(사용자 확인). 효능 표현은 상세페이지·패키지에 이미 쓰인 문구만 쓴다(`FACTS.md`).
- 스타일 시스템은 이전 편집과 같다. 종이색 바탕, 먹, 라임 하나(이번에는 라임 = 에너지), 6단 그리드, 120 bpm, 클립 리빌과 칼로 자르기를 쓰고 페이드는 쓰지 않는다.

| 시간 | 역할 | 장면 | 화면 문구 |
|---|---|---|---|
| 0–4.5 | 훅(공감) | 화면 전체가 배터리. 라임이 100%에서 10%까지 박자마다 줄어듦 | 100% → 10% / 오늘도 방전? |
| 4.5–10.5 | 대상 | 화면을 3칸으로 나눠 세 사람의 순간, 각자 10% 배터리 | 15:00 회의 끝난 오후 · 07:00 운동 시작 전 · 22:00 아이 재운 밤 |
| 10.5–15.5 | 해결 | 큰 배터리가 4단계로 100%까지 충전 | 한 잔 더 대신 / 하루 1포 / 올리고파 / 하루 1포로 에너지 UP |
| 15.5–22 | 이유 1 | 실제 함량 길이의 막대(1칸 = 250mg) | 고함량 에너지 부스터 / 4가지 원료 함량 |
| 22–30 | 이유 2 | 라임 막대로 들어가, 큰 블록을 칼로 잘라 16조각 → 2~8배 | 리치추출분말 Oligonol® / 생체이용률이 높은 폴리페놀 / 저분자 폴리페놀 2~8배 (원료사 자료 기준) |
| 30–36 | 루틴 | 스틱 14개, 01번만 라임 | 상큼한 리치맛 / 15g × 14포 / 하루 1포, 2주 루틴 |
| 36–42 | 제품 + 행동 유도 | 흰 종이 위 실제 패키지, 하단 라임 띠 | 올리고파 / 의사 공동개발 · HACCP · RAPHAHEAL / 지금 만나보세요 · 프로필 링크 클릭 → |

모든 문구는 초당 6자 + 1.5초 기준을 통과한다(`readcheck --cjk-cps 6`).
