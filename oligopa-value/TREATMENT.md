# 올리고파 — 39초 세로 광고, 가치 중심 편집 + 나레이션 (Swiss Motion Graphics)

- 규격: 1080×1920, 24 fps, 39초. 사용자 나레이션 녹음(`voices/narration.wav`, 31.2초) + 인쇄물 효과음, 배경음악 없음.
- 화면은 나레이션에 맞췄다. 녹음의 쉼(silencedetect)으로 나눈 구간을 대본의 음절 수와 맞춰 각 문구가 말해지는 순간에 등장하게 했다. 녹음은 세 조각으로 나눠 놓았다(0–26.16초 → 0초, 26.16–28.75초 → 27.5초, 28.75초–끝 → 31.94초). 두 번의 짧은 틈은 비교 화면과 스틱 14개 화면이 읽힐 시간을 준다(`film.js` 의 `VOICE`).
- 음성 인식 모델을 받을 수 없는 환경이라 마지막 구간(원본 29.1–31.0초)의 말은 확인하지 못했다. 그 구간은 제품·행동 유도 화면 위에 놓인다.
- 이전 편집(`../oligopa-swiss/`)에 "그래서 보는 사람에게 뭐가 좋은지 안 나온다"는 피드백이 있었다. 성분 나열을 앞에 두지 않고, **보는 사람의 상황 → 해결 → 이유 → 루틴 → 제품 → 행동 유도** 순서로 다시 짰다.
- 제품 분류: 건강기능식품(사용자 확인). 효능 표현은 상세페이지·패키지에 이미 쓰인 문구만 쓴다(`FACTS.md`).
- 스타일 시스템은 이전 편집과 같다. 종이색 바탕, 먹, 라임 하나(이번에는 라임 = 에너지), 6단 그리드, 120 bpm, 클립 리빌과 칼로 자르기를 쓰고 페이드는 쓰지 않는다.
