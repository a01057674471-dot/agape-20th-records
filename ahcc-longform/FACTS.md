# 면역과 AHCC, 확인된 사실만 — 화면과 대본의 근거

브랜드(라파힐) 유튜브 계정용. 건강기능식품 광고 규정(식품 등의 표시·광고에 관한 법률 제8조: 질병의 예방·치료 효능 표방 금지)에 맞춰 **질병·암 관련 연구는 다루지 않는다.** 암 질문은 Q&A에서 "건강기능식품은 질병의 예방·치료를 위한 의약품이 아니다"로만 답한다. 게시 전 한국건강기능식품협회 표시·광고 자율심의를 받는다.

| 화면·대본 | 근거 |
|---|---|
| 백혈구 100개 중 림프구 20~40개, 호중구 40~60개, 단핵구 2~8개 | MedlinePlus "Blood differential test": neutrophils 40–60 %, lymphocytes 20–40 %, monocytes 2–8 %, eosinophils 1–4 %, basophils 0.5–1 % (https://medlineplus.gov/ency/article/003657.htm). 와플은 범위 안의 한 사람 예시(58·30·7·4·1)이며 화면에 그렇게 적었다 |
| NK세포 · 림프구의 약 3~14% | 건강인 참고 범위로 보고된 CD3−CD16+/56+ NK세포 3~14 % of lymphocytes (연구용 유세포 분석 표). 검사실·마커에 따라 다르다 → "대략", "사람마다 다르다"로 표현 |
| 호중구는 세균과 맞섬, 단핵구는 청소, 수지상세포는 정보를 전하는 전령, 선천/적응 면역을 잇는 다리, NK세포는 선천 면역 | 면역학 교과서 수준의 일반 설명 |
| AHCC = 표고버섯 균사체를 액체 배지에서 배양, 분리·살균·동결건조 / 건조 중량의 약 74 %가 올리고당 | Shin et al., *Journal of Immunology Research* 2019 리뷰 (https://www.ncbi.nlm.nih.gov/pmc/articles/PMC6942843/), drugs.com |
| 'AHCC'는 아미노업의 등록 상표, 일본 삿포로 | Wikipedia AHCC (https://en.wikipedia.org/wiki/AHCC) |
| 1980년대 후반 도쿄대 약학부 연구진과 개발 (1987/1989, 자료마다 다름) | Wikipedia(1989, 도쿄대 약학부 오카모토 도시히코), Drugs.com(1987, 도쿄대 약학부). 둘 다 포함하는 표현으로 썼다 |
| 30년 넘게 이어진 연구 · 2026 | 1987/1989 → 2026 = 37~39년 |
| 2005년부터 UC 데이비스 영양학과 석학 강연 후원 | UC Davis Kosuna Distinguished Lecture (https://nutrition.ucdavis.edu/node/14641) |
| 국제학회 ICNIM 매년 개최 | 라파힐 상세페이지 "통합의료 기능성식품 국제학회(ICNIM) … 매년 개최되고 있습니다" |
| 표고버섯균사체 AHCC · 식약처 개별인정 제2008-78호 · 면역기능 증진에 도움을 줄 수 있음 | 라파힐 상세페이지, 관련 기사(코메디닷컴 등). 게시 전 식품안전나라에서 인정번호를 다시 확인 |
| 개별인정 = 제출된 안전성·기능성 자료를 식약처가 심사해 그 원료에만 인정 | 건강기능식품 개별인정형 원료 제도(건강기능식품에 관한 법률) |
| 건강한 성인 인체시험, 섭취 뒤 수지상세포 수 증가 보고 (Terakawa 외, 2008) | 라파힐 상세페이지 인용: "Immunological effect of AHCC in healthy volunteers", 2008. 수치는 화면에 그리지 않았다 |
