# 맨손 겨울 러닝 — 화면의 숫자와 출처

영상은 실제 인물의 기록이 아니라 **연구 결과를 바탕으로 한 시뮬레이션**이다(HUD에 "연구 기반 시뮬레이션" 상시 표기).

| 화면 | 근거 |
|---|---|
| 체감 −15°C / −20°C / −26°C | 캐나다·미국 기상청의 체감온도 공식 WCI = 13.12 + 0.6215T − 11.37V^0.16 + 0.3965T·V^0.16 으로 계산. 손이 느끼는 바람 V = 달리기 속도 + 맞바람. −10°C·10 km/h(6분/km) → −15.3; −10°C·30 km/h(+맞바람 20) → −19.5; −15°C·30 km/h → −26.1 |
| −27°C 아래 = 동상 위험 급증 | 캐나다 환경부 체감온도 포스터: "risk of frostbite increases rapidly when wind chill values go below −27" ([poster](https://www.Canada.ca/content/dam/eccc/migration/main/meteo-weather/80b0f2af-9697-4bee-ab17-d401ebba5b4b/windchill_poster_en.pdf)); 캐나다 적십자 표: −28 ~ −39에서 노출 피부는 10~30분 안에 얼 수 있음 ([Red Cross](https://www.redcross.ca/crc/documents/In%20your%20community/Manitoba/Tips_Cold_emergencies_EN.pdf)) |
| 손가락 15°C, 손놀림 급격히 저하 | 손가락 피부 12~20°C에서 손재주 저하, 15°C를 뚜렷한 저하 지점으로 보는 것이 일반적 ([Physiological Reports 2025](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC12059468/)); 15~16°C에서 큰 저하(Schiefer 등) |
| 16명 · 8°C 물 · 하루 30분 · 15회 | Daanen, Koedam & Cheung (2011) *Eur J Appl Physiol* 112:2595–2601, "Trainability of cold induced vasodilation in fingers and toes" ([PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC3371333), [PDF](https://research.vu.nl/ws/files/649238/298782.pdf)). 남 9·여 7명, 오른손·발을 8°C 물에 30분, 15회(주 5일, 약 3주) |
| 통증 ↓, 손가락 온도 ↓, 스스로 데워지는 반응 52% → 24%, 촉각 ↓ | 같은 논문: 훈련한 손의 평균 손가락 온도 하락, CIVD(한랭 혈관 확장) 발생 52% → 24%, 통증 보고 감소, 촉각 민감도 저하 |
| 덜 아픈 건 적응이 아니라 둔해진 것 / 동상 위험이 커질 수 있다 (연구진) | 같은 논문의 결론: 반복적인 손가락 냉각은 유리한 적응을 만들지 않고 오히려 부상 위험을 높일 수 있다 |

## 단서

- 반전의 근거는 달리기가 아니라 손을 찬물에 담근 실험실 연구다. 화면에 "손을 8°C 물에 담근 실험실 연구 기준"을 표기했다.
- 손의 냉 적응 연구는 결과가 엇갈린다(적응한다는 2008년 연구도 있다). 최근 연구와 리뷰의 대세는 "손 혈류는 거의 적응하지 않는다"이다 ([VU 리뷰](https://research.vu.nl/en/publications/dynamic-adaptation-of-the-peripheral-adaptation-to-cold-exposure/), [PubMed 39488057](https://pubmed.ncbi.nlm.nih.gov/39488057/)).
- 체크리스트("얇은 장갑 + 벙어리장갑", "하얗게 질리고 감각 없으면 중단")는 일반적인 동상 예방 안내이며 위 연구의 결과가 아니다.
- PMC 논문 원문은 이 작업 환경에서 열 수 없어, 실험 수치는 검색으로 확인한 초록·요약에서 가져왔다.
