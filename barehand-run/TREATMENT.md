# 만약 겨울 내내 영하에서 맨손으로 달린다면? — 35초 릴스 (Pictogram Motion)

- 규격: 1080×1920, 24 fps, 35초, 120 bpm(1박 = 0.5초). 음성 없음, 음악 + 효과음.
- 스타일: Pictogram Motion. 기하학 러너 픽토그램, 격자 패턴 배경(행이 박자마다 미끄러짐), 큰 한글 제목, 모노 HUD, 8칸 진행 막대. 모든 컷은 박자 위의 띠 미끄러짐 전환.
- 팔레트(자작): Polar Night · Black Ice · Frost Teal · Snowfield · Hot Hand. 맨손은 항상 따뜻한 원(빨강), 장갑은 앰버 캡슐.
- 이야기: 러너의 상상 → 숫자(바람) → 한 번의 러닝 → "겨울 내내"의 실험 → 반전 → 체크리스트 → 댓글 유도.

소리: 달리기 그루브(킥·스네어·16분 하이햇·보폭 셰이커·핑거 베이스, D단조), 얼음 같은 글로켄슈필. 숫자가 바뀔 때마다 탐 필 + 킥, 경고에 얼음 깨지는 소리, 실험 카드에 물소리와 카운트 틱, 반전 직전 반 박 정적 뒤 팀파니·서브 드롭과 하프타임. −14 LUFS.
