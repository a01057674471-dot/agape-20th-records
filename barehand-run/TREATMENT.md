# 만약 겨울 내내 영하에서 맨손으로 달린다면? — 30초 릴스, 나레이션 1.5배속 (Pictogram Motion)

- 규격: 1080×1920, 24 fps, **30초**, 150 bpm(1박 = 0.4초). 사용자 나레이션(TTS 녹음) + 음악 + 효과음.
- 나레이션: 원본 녹음(`voices/source.mp3`, 62.6초)을 쉬는 구간 30개로 나눠 대본 30구절과 맞춘 뒤, **핵심 21구절만 남기고 각각 1.5배속**(음높이 유지)으로 붙였다(`tools/voice.py` → `voices/narration.wav`, `voices/times.js`). 뺀 구절: 달리면 바람이 생깁니다 / 맞바람 20km·영하 26도 단계 / 결과는 / 손가락 온도는 더 낮아졌고 / 감각도 둔해졌죠 / 손이 하얗게 질리면 바로 멈추세요.
- 화면은 나레이션 타임라인을 그대로 읽는다. 각 카드는 8분음표 격자 위에서 시작하고, 카드의 문구는 카드가 열릴 때 함께 올라온다. 모든 문구가 소리로도 나오므로 읽기 검사는 초당 8자 기준이며, 제목·"덜 아픈 건 적응이 아니라"·"체감 −27°C 아래 장갑 필수"는 그보다 조금 짧게 보인다(나레이션이 읽어준다).
- 효과음으로 집중: 컷마다 휙 + 낮은 타격, 글줄이 올라올 때마다 틱, 숫자에 탐 필, 경고에 얼음 깨짐, 실험 카드에 물소리와 카운트, 반전 직전 상승음 → 반 박 정적 → 팀파니·서브 드롭.
- 스타일: Pictogram Motion. 기하학 러너 픽토그램, 격자 패턴 배경(행이 박자마다 미끄러짐), 큰 한글 제목, 모노 HUD, 8칸 진행 막대. 모든 컷은 박자 위의 띠 미끄러짐 전환.
- 팔레트(자작): Polar Night · Black Ice · Frost Teal · Snowfield · Hot Hand. 맨손은 항상 따뜻한 원(빨강), 장갑은 앰버 캡슐.
- 이야기: 러너의 상상 → 숫자(바람) → 한 번의 러닝 → "겨울 내내"의 실험 → 반전 → 체크리스트 → 댓글 유도.
