# 올리고파 — 38초 세로 광고 트리트먼트

- 스타일: Dark Tech Keynote (`styles/dark-keynote/STYLE.md`)
- 규격: 1080×1920 세로(릴스·쇼츠), 24 fps, 38초, 음성 없음(음악·효과음·화면 문구)
- 출처: 사용자가 준 라파힐 올리고파 상세페이지 이미지. 화면 문구와 수치는 모두 거기서 가져온다(`FACTS.md`).
- 표현 기준: 제품 분류를 확인받지 못해 **일반식품 기준**으로 만든다. 맛, 원료, 함량, 구성, 브랜드가 이미 패키지에 쓰는 카피만 쓰고, 효능·기능성(순환, 피로, 운동 능력 등)은 말하지 않는다. 원료 비교 수치에는 "원료사 자료 기준"을 화면에 표기한다.

## 스타일 선택 이유와 바꾼 점

- 라이브러리에서 실물 제품을 다루는 Glass Product Render는 "가상의 물체만, 실제 브랜드·로고 금지"가 규칙이라 실제 제품 광고에 쓸 수 없고, GPU 렌더링이 필요하다.
- Dark Tech Keynote는 원래 소프트웨어 출시 영상용이지만, 검은 무대, 하나의 강조색, 빛이 지나간 곳만 켜지는 공개, 숫자가 글자 노이즈에서 고정되는 연출이 "고함량 에너지 제품"의 가치를 보여주기에 가장 잘 맞는다.
- 바꾼 점: 주인공을 소프트웨어 화면 대신 **성분 카드(UI 타일)**로 삼고, 실제 패키지는 마지막에 빛으로 공개하는 "제품 카드"로 넣는다. 강조색은 패키지의 형광 연두에 맞춰 라임 `#B7F34A` 하나만 쓴다.

## 1. 구조 후보

1. **숫자 먼저.** 검은 화면에 거대한 "1,000mg"이 글자 노이즈에서 고정되며 시작(훅) → 한 포에 든 4가지 카드 → 리치추출분말 → 저분자 폴리페놀 비교 → 14포 → 제품 공개. 첫 1초에 시선을 잡고, 뒤로 갈수록 왜 다른지(가치)를 쌓는다.
2. **줌 사다리.** 리치 한 알 → 폴리페놀 분자 → 한 포 → 한 상자로 계속 빠져나온다. 시각적으로 좋지만 함량 수치가 들어갈 자리가 약하다.
3. **비교 분할 화면.** 일반 폴리페놀 vs 올리고파를 나란히. 비교가 영상 대부분을 차지해 다른 장점(맛, 함량)이 묻힌다.

**선택: 1번.** 릴스에서는 첫 화면의 큰 숫자가 가장 강한 훅이다.

## 2. 로그라인

한 포에 L-아르지닌 1,000mg부터 저분자 폴리페놀 원료 리치추출분말(Oligonol®)까지, 상큼한 리치맛 에너지 부스터 올리고파를 38초 안에 숫자와 빛으로 보여준다.

## 3. 숏과 비트 (120 bpm, 1마디 = 2초)

| 시간 | 장면 | 화면 문구 | 연출 |
|---|---|---|---|
| 0.0–0.4 | 검은 무대, 라임 번개 한 줄기가 번쩍 | — | 훅: 첫 프레임부터 움직임, 낮은 임팩트 소리 |
| 0.4–3.75 | 거대한 숫자가 노이즈에서 한 자리씩 고정 | **1,000mg** / L-아르지닌 · 1포 기준 | 숫자 카운트 잠금(네이티브 무브), 라임 글로우 |
| 3.75–7.5 | 숫자가 카드로 줄어들고 3장이 날아와 2×2 그리드에 스냅 | 한 포에 담은 4가지 / 4가지 함량 카드 | 스냅 그리드, 각 카드 숫자 스크램블 |
| 7.5–12.5 | 리치추출분말 카드로 다이브 → 리치 열매가 빛으로 드러남 | 리치추출분말 Oligonol® / 리치 열매에서 추출한 폴리페놀 | 카드 확장 전환, 라이트 리빌 |
| 12.5–19.75 | 큰 폴리페놀 분자 덩어리가 작은 조각들로 쪼개짐(16초) | 폴리페놀, 크기가 다르다 / 저분자 폴리페놀이 풍부 | 분자 쪼개짐에 맞춰 글라스 탭 소리 |
| 19.75–20.0 | 완전한 정적 | — | 소리와 룸톤까지 0 |
| 20.0–26.0 | 막대 4개가 차오름(올리고파만 라임) → 숫자 "2~8배" | 일반 폴리페놀 원료 대비 저분자 폴리페놀 **2~8배** / *원료사 자료 기준 | 막대는 박자에 맞춰 하나씩 |
| 26.0–33.0 | 리치 반쪽이 반짝이고, 스틱 14개가 2×7 그리드로 스냅 | 상큼한 리치맛 / 15g × 14포, 하루 1포 | 스냅 그리드 |
| 33.0–38.0 | 그리드가 접히며 패키지 사진이 빛으로 공개, 번개 | **올리고파** / 하루 1포로 에너지 UP / 의사 공동개발 · HACCP · RAPHAHEAL | 라이트 리빌, 마지막 3초 정지 |

**길이를 30초에서 38초로 늘린 이유:** 한국어 문구는 초당 6자 기준(+1.5초)으로 읽을 시간이 필요하다(`readcheck --cjk-cps 6`). 30초로는 10줄이 읽히기 전에 사라져, 장면마다 시간을 늘렸다. 모든 줄이 기준을 통과한다.

**스타일에서 벗어난 점:** 리치 열매는 실제 색(장밋빛 `#B8606E`)으로 그렸다. 강조색 하나 규칙의 예외지만, 제품의 맛과 원료를 알아보게 하는 정체성 요소라 남겼다.

## 4. 카메라

- 0–3.75초 숫자에 고정된 익스트림 클로즈업 → 3.75초 휩 풀아웃(카드 그리드) → 7.5초 카드로 다이브 → 20초 차트 앞 홀드 → 33초 제품 카드에 프레젠테이션 홀드(빛 스윕).
- 모든 전환은 UI가 화면으로 펼쳐지거나 화면이 카드로 접히는 방식. 페이드와 빈 프레임 없음.

## 5. 소리

- 120 bpm. 마림바·비브라폰·글로켄슈필의 가산 빌드(마디마다 음 하나씩 추가), 낮은 사인 펄스, 셰이커.
- 숫자 잠금마다 디지트 그레인, 카드 스냅마다 펠트 틱(한 음계 안에서 쌓이는 반짝임), 번개는 짧은 크랙 + 서브 드롭.
- 19.75–20초 차트 직전 반 박 완전한 정적, 다음 첫 소리는 첫 막대.
- 마지막 E장조 화음 하나에 모든 게 착지(33.75초), 끝까지 울림. −14 LUFS.

## 6. 글자

- 한글: Noto Sans KR(300/500/800, OFL), 숫자: Inter Tight 600(OFL), 작은 라벨: JetBrains Mono(OFL).
- 한 화면에 헤드라인 한 줄. 큰 숫자 화면에는 다른 문구를 겹치지 않는다(라벨만 작게).
- 출처 표기는 해당 장면 하단에 작은 회색 글씨로.
